# STSO 30. Komite - Seçim Kontrol Listesi

GitHub Pages üzerinde çalışan HTML, CSS ve JavaScript arayüzü.

Geldi, Belge, Oy ve Not alanları ekip tarafından ortak kullanılır. Kayıtlar ayrı bir özel GitHub deposunda tutulur. Görünür sekmeler yaklaşık üç saniyede bir güncellenir; güncelleme aralığı GitHub ve internet bağlantısına bağlıdır.

`config.json`, yerel kurulum aracıyla hazırlanan kullanıcı yapılandırmasıdır. Ortak kayıt bağlantısı kurulmadan giriş etkinleşmez. Kişi kayıtları, yedekler veya düz erişim anahtarları bu açık depoya eklenmemelidir.
